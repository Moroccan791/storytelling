# Topic banks

Scored idea bank for the on-demand flow. Nothing here has been made yet — the
"made" column is the tracker.

**Scoring.** Curiosity: would a stranger stop scrolling? (1-5) · Visual: can
images show it? (1-5) · Risk: how likely is a number to be wrong or
contested? (1-5, **lower is better**). Total = curiosity + visual − risk.

Anything with **risk ≥ 3 must be fact-checked with two sources before it is
built**, however well it scores.

## Rules for using this list

1. **Do not repeat a premise, a plot or a twist**, including across formats.
   Mark the row `Made` with the video id when it ships.
2. **Format B: two named sources per fact before building.** If a claim
   cannot be confirmed twice, it is dropped, not softened.
3. Any claim still scored **risk ≥ 3** gets a note in `sources.md` and is
   flagged for you in the report — I will not quietly smooth it over.
